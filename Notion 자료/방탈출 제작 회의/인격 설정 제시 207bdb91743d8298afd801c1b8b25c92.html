수정 부분:

인격 관련 설정 전반

수정 관련 사유:

현재 시나리오에서는 알렉스, 릴리, 오펠리아, 노아가 모두 에바 내부의 인격이지만, 1부에서는 실제로 존재하는 여러 사람처럼 행동하고 서로 대화하며 기록을 남긴 것으로 묘사됨.

따라서 다음 부분의 설정을 명확히 할 필요가 있음.

  1. 에바가 언제부터 각 인격을 실제 사람처럼 인식했는가.
  1. 실제 육체가 하나인데 여러 인격이 서로 대화하거나 싸우는 장면을 어떻게 해석해야 하는가.
  1. 각 인격이 자신이 에바의 일부라는 사실을 알고 있는가.
  1. 서로 다른 인격이 남긴 기록과 행동을 어떻게 설명할 것인가.
  1. 노아가 다른 인격에게 영향을 미치는 장면을 별도의 ‘주도권’ 설정 없이 어떻게 설명할 것인가.

현재 시나리오에서도 2부에서 모든 인물이 에바의 인격이었다는 사실과, 1부의 사건들이 실제로는 한 사람에게 일어난 일이었다는 반전이 핵심으로 사용되고 있음.

현재 인격 설정:

1. 에바는 어릴 때부터 여러 인격을 가지고 있었다.

에바는 어릴 때부터 알렉스, 릴리, 오펠리아, 노아와 같은 인격을 만들어냈다.

처음에는 자신이 만들어낸 친구라는 사실을 어느 정도 알고 있었지만, 오랜 시간 이들과 함께 지내면서 점차 각 인격을 자신과 분리된 실제 친구처럼 받아들이게 됨.

따라서 에바는 제온에 노출되기 전부터 이들을 실제 사람처럼 보고, 듣고, 함께 행동한다고 인식하고 있었음.

제온은 이 현상을 만들어내거나 심화시키지 않음.

제온과 인격의 직접적인 관계는 별도로 존재하며, 에바가 다른 인격들을 실제 사람처럼 인식하는 현상 자체는 원래부터 있었던 것임.

2. 실제로 존재하는 육체는 에바 한 명뿐이다.

알렉스, 릴리, 오펠리아, 노아가 서로 대화하거나 싸우고, 한 사람이 다른 사람의 방으로 이동하는 것처럼 묘사되더라도 실제로 여러 사람이 움직인 것은 아님.

실제로는 모든 행동을 에바 한 명이 하고 있음.

다만 각 인격이 사건을 인식할 때는 다른 인격들이 자신의 앞에 존재하고, 각각 독립적으로 행동하고 있는 것처럼 받아들임.

따라서

노아가 에바를 공격한다.

릴리가 에바의 밧줄을 풀어준다.

에바가 노아를 뿌리치고 달아난다.

와 같은 장면도 실제 육체의 움직임 자체는 에바 한 명에게서 일어난 행동임.

하지만 최종적인 결과는 각 인격이 인식한 사건과 동일하게 남음.

인격 간 상호작용:

각 인격은 다른 인격을 실제 사람처럼 인식하기 때문에 서로 대화하고 행동하는 장면도 자연스럽게 여러 사람 사이의 사건으로 기억함.

따라서 현재 시나리오에 존재하는 메모, 일지, 통신 기록 등도 각 인격이 자신이 경험했다고 믿는 1인칭 시점을 기록한 문서라고 볼 수 있음.

예를 들어 에바가

“노아가 나를 붙잡았다.”

라고 기록했다면, 실제로 노아라는 별개의 사람이 에바를 붙잡은 것은 아님.

하지만 에바 인격에게는 실제로 노아에게 붙잡힌 것과 동일한 사건으로 인식되었기 때문에 기록 역시 그렇게 남음.

기록물의 진실 연출:

1부에서는 모든 기록을 기존처럼 알렉스, 릴리, 오펠리아, 노아, 에바라는 서로 다른 사람이 작성한 것처럼 보여줌.

2부에서 진실이 밝혀지는 시점에 대표적인 기록 하나를 다시 보여주며, 문장 속 인물 이름이 하나씩 에바로 바뀌는 연출을 사용함.

예를 들어

오펠리아 → 에바

노아 → 에바

릴리 → 에바

와 같이 모든 이름은 에바로 바뀌지만, 글자의 색깔은 기존 인격의 대표색을 유지함.

이를 통해 플레이어에게

‘사건은 실제로 일어났다. 다만 그 모든 행동을 한 사람은 에바 한 명이었다.’

는 사실을 시각적으로 전달함.

이후 다른 기록들도 같은 방식으로 이름이 에바로 변경된 상태로 확인할 수 있게 함.

현재 노아 방 2부에서 계획되어 있는 ‘모든 이름이 에바로 바뀌고 색깔만 각 인격의 색을 유지하는 연출’과 그대로 연결할 수 있음.

각 인격이 알고 있는 진실:

릴리를 제외한 인격들은 자신들이 에바의 인격이라는 사실을 모름.

알렉스, 오펠리아, 노아는 자신을 에바와 별개의 실제 사람이라고 생각함.

에바 역시 마찬가지로 자신과 네 명의 친구가 실제로 함께 존재한다고 생각함.

릴리만 처음부터 모든 사람이 에바의 인격이라는 사실을 알고 있음.

릴리는 에바가 이 사실을 받아들이지 못할 것을 알고 있기 때문에 이를 다른 인격들과 에바에게 직접 밝히지 않음.

현재 릴리의 2부 장면에서 릴리가 다른 인격들과 달리 진실을 알고 있었으며, 에바가 상처받지 않도록 계속 숨겨 왔다는 설정과 연결됨.

다만 릴리만 진실을 알고 있었다는 사실에 대한 1부 복선은 현재 부족함.

이에 대한 구체적인 복선 추가는 별도의 토론이 필요함.

‘주도권’ 관련 설정:

별도의 ‘인격이 몸의 주도권을 얻는다’는 규칙은 만들지 않음.

각 인격이 어떤 조건에서 등장하고 사라지는지, 누가 신체를 조종하고 있는지를 세부적인 시스템으로 설명하면 오히려 설정이 복잡해질 가능성이 있음.

노아와 제온:

노아에게 발생한 특수한 현상은 다른 인격들이 했던 행동이나 가지고 있던 기억을 어렴풋이 인식하게 된 것임.

노아는 자신이 직접 경험하지 않은 알렉스와 에바 등의 행동을 부분적으로 알게 되고, 이를 실제 타인의 생각을 읽는 것처럼 받아들임.

그 결과 알렉스와 에바가 무언가 숨기고 있다고 의심하게 되고, 다른 인격들의 기록과 행동을 조사하기 시작함.

현재 1부의 노아 기록에 있는

“그러다 보니 무슨 생각을 하는지 보이더군.”

이라는 표현도 실제 독심이라기보다 이 현상을 노아가 그렇게 해석한 것으로 볼 수 있음.

이 설정은 복잡하므로 그냥 책자에 넣을 예정이며, 방탈출 내에서는 편집증 정도로 묘사 예정

인격의 역할:

각 인격을 ‘본능 그 자체’로 정의하지는 않음. 다만 에바가 각 인격을 만들 때 특정한 역할과 성격이 강하게 반영되어 있음.

알렉스는 책임, 명령, 리더십이 두드러짐.

릴리는 보호와 기억 관리가 두드러짐.

오펠리아는 탐구와 분석이 두드러짐.

노아는 계산, 위험 판단, 장난기와 포기 성향이 두드러짐.

VEA는 생존 의지가 강하게 드러남.

이는 각 인격의 성격을 이해하기 위한 보조적인 해석이며, 본편에서 “이 인격은 ○○본능이다.” 라고 직접 정의하지 않음. 이 역시 책자용 설명

시나리오에서 해결된 부분:

1. 여러 인격이 실제 사람처럼 상호작용하는 문제

실제로 여러 명이 행동한 것이 아니라, 에바 한 명의 행동을 각 인격이 여러 사람 사이에서 벌어진 사건처럼 인식한 것으로 정리함.

따라서 사건의 결과 자체는 유지하면서 인물이 여러 명 존재했다는 부분만 2부에서 뒤집을 수 있음.

2. 서로 다른 인격이 서로 다른 기록을 남기는 문제

각 기록은 해당 인격이 자신이 경험했다고 믿는 사건을 작성한 것임.

에바 한 명이 서로 다른 시점에 서로 다른 인격의 입장에서 기록을 남겼기 때문에 문체, 매체, 관점이 달라도 설정상 문제되지 않음.

3. 왜 아무도 다른 팀원이 보이지 않는 것을 이상하게 생각하지 않는가

각 인격의 인식 안에서는 다른 인격들이 실제 사람처럼 존재함.

따라서 ‘왜 아무도 없지?’라는 의문 자체가 발생하지 않음.

실제 공간에서는 에바 혼자 행동하지만, 에바와 각 인격에게는 여러 사람이 존재하는 상황으로 인식됨.

4. 제온이 인격 환각을 만든다는 기존 설명

삭제함.

에바는 어릴 때부터 다른 인격을 실제 친구처럼 인식하고 있었으며, 제온은 이 현상을 만들어내거나 심화시키지 않음.

추가로 해결해야 하는 부분:

1. 릴리가 진실을 알고 있었다는 복선

릴리만 자신과 다른 인물들이 모두 에바의 인격이라는 사실을 알고 있었음.

하지만 현재 1부에서는 릴리 역시 다른 사람들과 완전히 동일하게 행동하는 것처럼 보이기 때문에, 2부에서 이 사실이 갑자기 추가된 설정처럼 느껴질 가능성이 있음.

따라서 릴리의 기록이나 행동 중 일부에

‘릴리는 다른 인격들과 달리 뭔가를 알고 있었다.’

고 나중에 재해석할 수 있는 복선이 필요함.

구체적인 복선은 별도 토론에서 결정함.

2. 노아의 최초 제온 노출 과정

오펠리아와 노아가 같은 몸이므로 기존의

‘오펠리아의 실험실에서 제온이 유출되고 지나가던 노아가 마셨다.’

는 설명은 그대로 사용할 수 없음.

이 부분은 제온 설정과 함께 별도로 수정해야 함.

현재 인격 설정 요약:

확정된 설정

에바는 어릴 때부터 여러 인격을 가지고 있었다.

에바는 각 인격을 실제 친구처럼 보고 듣고 있었으며, 제온은 이 현상과 관계없다.

실제로 존재하는 육체는 에바 한 명뿐이다.

여러 인격이 상호작용하는 것처럼 보이는 사건 역시 실제 행동은 전부 에바 한 명이 하고 있다.

각 인격은 자신이 경험한 사건을 실제 여러 사람 사이에서 벌어진 일처럼 인식하고 기록한다.

2부에서 기록 속 모든 인물의 이름이 ‘에바’로 바뀌고, 기존 인격의 대표색만 유지되는 연출을 통해 이를 보여준다.

릴리만 모든 인격이 에바의 일부라는 사실을 알고 있었다.

에바, 알렉스, 오펠리아, 노아는 자신들을 서로 다른 실제 사람이라고 믿는다.

별도의 ‘주도권’ 시스템은 설정하지 않는다.

제온은 기존 인격을 실제 친구처럼 보는 현상을 만들거나 심화시키지 않는다.

노아에게만 다른 인격들의 행동과 기억이 어렴풋이 전달되는 특수한 현상이 발생한다.

각 인격에는 특정 역할과 성향이 두드러지지만, 이를 본편에서 ‘본능’이라고 직접 정의하지 않는다.

추가 논의가 필요한 설정

릴리만 진실을 알고 있었다는 사실에 대한 1부 복선.

노아가 최초로 제온의 영향을 받게 된 구체적인 과정.
