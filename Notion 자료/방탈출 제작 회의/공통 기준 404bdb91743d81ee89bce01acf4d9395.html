5. 공간·기기·공통 화면

릴리의 핸드폰 — 퀘스트·힌트 안내 기준

힌트폰은 이야기 속 ‘릴리의 핸드폰’이다. 현재 해야 할 일과 다음 조사 장소를 퀘스트처럼 안내하고, 필요한 경우 현재 문제의 힌트를 제공한다.

  • 1부: 릴리가 미리 만들어 둔 프로그램이 안전 모드를 해제하는 순서를 안내한다. 알렉스 → 오펠리아 → 노아 → 오펠리아 재방문 → 에바 → 릴리 순으로 현재 목표를 보여 준다.
  • 2부: 비아가 힌트폰에 들어와 안내하는 연출로 전환한다. 비아는 이미 확인한 기록과 현재 상황을 바탕으로 다음 조사 방향을 제시한다.
  • 이동·진행 안내와 퍼즐의 단계별 힌트는 구별한다. 문제 1에 별도 힌트·힌트 코드를 만들지 않는 기준은 유지한다.
  • 목표 완료는 실제 문제·기록·승인 상태에 맞춰 갱신하며, 다음 기록이나 반전·정답을 먼저 공개하지 않는다.
  • 휴대폰에서의 비아 안내는 기존 제6인격 설정에 맞춘 화면 연출이다. 실제 AI 프로그램이거나 릴리가 만든 인격이라는 설정으로 바꾸지 않는다.

디자인팀은 모바일 화면을 디자인하고, 개발팀은 이를 실행하는 퀘스트·힌트 안내 앱을 제작한다. 상세 화면·상태 연결은 디자인 가이드와 개발 가이드에서 관리한다.

공간은 동아리방을 커튼으로 구분한다. 잠금문 대신 프로그램의 단계·열람 조건을 사용한다. 릴리에 메인 컴퓨터를 둔다. 확보 목표는 릴리 메인 컴퓨터 1대, 알렉스·오펠리아·노아·에바 태블릿 4대, 힌트폰 1대다. 확보 완료를 뜻하지 않는다. 모든 단말기는 네트워크로 연결하고 방별 조명은 구역을 밝히는 무드등 수준이다.

6. 두 팀이 함께 지킬 연결 기준

오펠리아 기록·암호 입력 기준

노아의 암호 ‘최적해’(문제 5)와 공동 연구 기록의 암호 ‘HEAL’(문제 11)은 모두 오펠리아 1부에서 ‘끝없는탐구’를 입력했던 동일한 보고서 암호 입력칸에 입력한다.

문제 11의 ‘HEAL’을 입력하면 ‘제온 공동 연구 기록’이 열린다. 공동 연구자는 오펠리아 그린·에바 펠로노르다. 개인 연구와 구분하기 위해 두 사람의 공동 연구 기록은 따로 모아 두었다. 문제지가 2부 오펠리아 방 금고에 있으므로 1부에는 열리지 않는다. 무단 열람이 확인된 이후에는 해당 구역에도 잠금을 적용했다.

  • 디자인은 정답을 이루는 글자·색·배열·겹침 위치를 비교적 보존한다. 개발은 같은 정답·배열을 사용한다.
  • 사원증은 문제 0·7이 같은 소품을 사용한다.
  • 별자리 필름은 문제 2·10이 같은 8장을 사용한다.
  • 색이 단서인 문구와 선은 별도로 식별해 전달한다.
  • ‘마지막 기록’ 치환 시 인물 이름만 EVA에 해당하는 ‘에바’로 바꾸며, 글자색·방 이름을 유지한다. 치환 전·후 상태를 구분한다.

7. 인계 기록

일감과 완료 체크는 행성·탈출 전체 수정 및 제작 계획서에서 관리한다. 이 문서에는 적용 사양만 둔다.
