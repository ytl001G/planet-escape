NPC 가이드

2인 운영을 전제로 한 초안. 수동 연출의 정확한 발생 시점, 복구 방법, 소품별 시작 위치는 아직 정해지지 않았다.

공통 원칙

  • 총괄 관리인원 1명, 일반 관리인원 1명으로 운영한다.
  • 참가자에게 현재 진행 단계 이후의 정답·기록·반전을 먼저 공개하지 않는다.
  • 문제 정답, 기록 열람, 인물 승인, 다음 장면 진입을 각각 구별한다.
  • 기기 오류나 소품 이상을 발견하면 일반 관리인원이 총괄에게 즉시 전달한다.
  • 진행 상태 변경, 연출 재실행, 회차 종료 판단은 총괄이 담당한다.

총괄 관리인원

시작 전

  • 메인 컴퓨터·방별 단말기·힌트폰의 회차 시작 상태를 확인한다.
  • 이전 회차의 입력·승인·힌트·연출·엔딩 기록이 남아 있지 않은지 확인한다.
  • 소품 배치 완료 여부를 일반 관리인원에게 확인한다.
  • 모든 기기와 음향이 준비된 뒤 시작을 진행한다.

진행 중

  • 현재 문제, 기록 열람, 인물 승인, 힌트폰 목표가 같은 단계에 있는지 확인한다.
  • 참가자의 문제 관련 질문과 힌트 요청에 답한다.
    • 진행 장소 안내와 퍼즐 풀이 힌트를 구별한다.
    • 현재 문제에 해당하는 정보만 제공한다.
    • 문제 1에는 별도 퍼즐 힌트를 제공하지 않는다.
    • 보너스 패턴 문제의 풀이 힌트를 제공하지 않는다.
  • 자동 진행되는 장면의 시작·종료와 중복 재생 여부를 확인한다.

자동화할 수 없는 이벤트

  • 복구제 소품의 복용 연출을 확인한다.
    • 확인 후에만 오펠리아 복귀 음성이 이어지도록 진행한다.
  • 참가자가 예상하지 못한 방식으로 문제를 풀거나 소품을 다룬 경우 진행 가능 여부를 판단한다.
  • 힌트폰의 운영자 호출과 현장 질문에 상황에 맞춰 응답한다.
  • 엔딩 종료 후 참가자에게 이야기와 선택 결과를 설명하며 마무리한다.

에러 시 복구가 필요한 이벤트

  • 기기 연결 끊김 또는 화면 멈춤
  • 정답 입력 후 기록·승인·다음 목표가 갱신되지 않음
  • 음성·영상·조명이 재생되지 않거나 중복 실행됨
  • 이미 본 기록이 잠기거나 다음 단계 자료가 먼저 공개됨
  • 레버 입력이 인식되지 않거나 엔딩이 중복 실행됨
  • 복구 전 현재 진행 단계와 참가자가 실제로 확인한 자료를 확인한다.
  • 복구 후 메인 컴퓨터·방별 기기·힌트폰의 상태가 일치하는지 확인한다.

엔딩·회차 종료

  • LOVE 완료 후 레버가 활성화되고, 그 전의 조작으로 엔딩이 실행되지 않는지 확인한다.
  • 참가자가 레버를 움직인 뒤 선택한 방향의 엔딩이 자동으로 한 번만 실행되는지 확인한다.
  • 보너스 성공 여부가 행성 엔딩의 후일담에 반영되는지 확인한다.
  • 참가자 퇴장 후 디지털 진행 상태를 초기화한다.
  • 일반 관리인원의 실물 리셋 완료 보고를 받은 뒤 다음 회차 준비 완료를 판단한다.

레버 자동화 사양 — 제작 제안

  • 플레이어가 레버를 직접 움직이고, 장치가 위·아래 위치 신호를 감지한다.
  • LOVE 완료 전에는 레버 신호가 들어와도 엔딩을 실행하지 않는다.
  • LOVE 완료 후 레버가 중립 위치에 있음을 확인하고, 그 뒤 새로 발생한 첫 유효 방향 신호만 처리한다.
  • 아래쪽 신호는 탈출 엔딩, 위쪽 신호는 행성 엔딩에 연결한다.
  • 레버가 중간에 걸리거나 접점이 튀는 경우에는 어느 엔딩도 실행하지 않는다.
  • 한 엔딩이 확정되면 반복 조작으로 다른 엔딩이 실행되지 않게 한다.
  • 엔딩 화면·음향·조명과 보너스 후일담 조건을 같은 회차 상태에 연결한다.
  • 중립 위치가 없는 레버를 쓰는 경우 LOVE 전 조작을 막을 물리적 잠금 또는 동등한 장치를 마련한다.
  • 탈출 엔딩의 전원 종료는 연출로 처리하고, 운영·복구에 필요한 장치 전원은 유지한다.
  • 센서·스위치 종류, 연결 방식, 고장 시 복구 절차는 제작 단계에서 정한다.

일반 관리인원

시작 전

  • 참가자를 맞이하고 기존 시작 전 안내를 진행한다.
  • ‘릴리의 팀원 관찰 기록’을 입장 전에 읽도록 전달한다.
  • 기록을 참가자 한 명이 들고 입장하도록 안내한다.
  • 힌트폰 사용과 운영자 호출 방법을 안내한다.
  • 금고·자물쇠는 문제의 단서에 따라 열고, 힘으로 열거나 임의로 분해하지 않도록 안내한다.
  • 소품과 기기의 시작 배치를 확인한 뒤 총괄에게 준비 완료를 보고한다.

진행 중

  • 참가자 호출에 응대하고 질문 종류를 확인한다.
  • 문제 풀이·정답·스토리 관련 질문은 총괄에게 전달한다.
  • 소품 파손, 기기 이상, 안전 문제를 확인해 총괄에게 즉시 전달한다.
  • 총괄이 진행 상태를 확인하는 동안 현장 참가자 응대를 담당한다.

종료 후·다음 회차 준비

  • 참가자 퇴장을 안내한다.
  • 사용한 소품을 회수하고 시작 상태로 복원한다.
  • 사원증, 별자리 필름, 책, 금고·열쇠, 핸드벨, 복구제 상자·약 소품, 문제 카드를 확인한다.
  • 단말기·힌트폰·음향 장치의 물리적 상태를 확인한다.
  • 실물 리셋 완료를 총괄에게 보고한다.

두 사람의 인계 기준

  • 시작: 일반 관리인원 소품 배치 완료 보고 → 총괄 디지털 상태 확인 → 참가자 입장
  • 오류: 일반 관리인원 현장 상황 전달 → 총괄 진행 상태 확인·복구 → 일반 관리인원 참가자 안내
  • 다음 회차: 일반 관리인원 실물 리셋 → 총괄 디지털 리셋 → 두 사람 모두 준비 완료 확인

아직 작성할 운영 자료

  • 장면별 자동 진행·사람 확인·오류 복구 구분표
  • 장면별 정확한 발생 시점과 복구 방법
  • 소품별 시작 위치 사진
  • 실물·디지털 리셋 완료 확인표
