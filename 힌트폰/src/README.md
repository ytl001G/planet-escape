# 힌트폰 논리도 만드는 법
`힌트폰_논리도.html`은 이 폴더의 스크립트로 만든 결과물이에요. 직접 고치지 말고 스크립트를 고친 뒤 다시 만들어요.

- 다시 만들기: `힌트폰` 폴더에서 `sh src/build.sh`
- 시험: `src/*_test.js`를 완성된 HTML 끝(`</body>` 앞)에 `<script>`로 넣고 헤드리스 크롬으로 열어요.
- 색·글자·크기 값은 `src/palette.py`, 우주선 지도는 `src/shipmap.py`, 시험판은 `src/proto.py`, 화면 그림은 `src/screens.py`.
